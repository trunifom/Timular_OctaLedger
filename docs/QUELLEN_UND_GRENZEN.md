# Quellen und Grenzen

Grundlagen:
- Bleak / Loop und Windows: https://bleak.readthedocs.io/en/latest/troubleshooting.html
- Streamlit Host/Client: https://docs.streamlit.io/develop/concepts/architecture/architecture
- Python src-Layout: https://packaging.python.org/en/latest/discussions/src-layout-vs-flat-layout/
- Community-Protokollreferenz: https://github.com/unixfg/triangles

Das Paket wurde bei Erstellung auf Dateikonsistenz, Python-Syntax und die enthaltenen
Unit-Tests geprüft. Nicht unter Windows ausgeführt; keine BLE-Hardwareprüfung;
keine vollständige Installation aller Drittanbieterabhängigkeiten in der Zielumgebung.
Kein laufender Agent, keine Datenbankimplementierung und keine fertige Zeitmessung.
Namens-/Lizenzwahl und echte Hardwarekompatibilität bleiben offen.
