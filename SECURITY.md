# Sicherheit

Keine Tokens oder privaten Zeitdaten in öffentliche Issues schreiben.
Das Grundgerüst enthält noch keinen laufenden API-Server und keine vollständige
Sicherheitsimplementierung. Vor Netzwerkfreigabe Authentifizierung, Origin-/Host-
Validierung und Zugriffsbeschränkungen implementieren. Erstversion nur Loopback.
Ein Projektbetreiber muss vor Veröffentlichung einen privaten Meldeweg ergänzen.
